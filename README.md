## 🛠️ Como trabalho neste repositório

- **Uma branch por módulo** (`mcN/modulo-N`) → commits pequenos → Pull Request → squash merge.
- **Commits** assinados e no padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/), em português.
- **Antes de cada commit**, o "botão verde" do minicurso (lint, tipos e testes) precisa passar.
- **Cada minicurso** tem o próprio README: como rodar, módulos, formatura e resumo.
